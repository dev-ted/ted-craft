# Pull request body

About 150 words. Lead with what the reviewer must decide. No evidence block: CI is the evidence. Delete a heading the pull request does not need. Do not leave it empty.

```markdown
## What changed and why

_

## Work item

_

## Decisions requested of the reviewer

_

## Out of scope / not done

_

## Risks

_

## AI involvement

- Label: `ai:none` | `ai:assisted` | `ai:generated`
- If `ai:generated`: tool and model
- If `ai:assisted`: what the agent produced
```
