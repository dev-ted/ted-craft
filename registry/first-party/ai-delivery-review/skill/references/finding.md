# Finding that outlives a pull request

Use a review comment while the pull request is open. Promote to the tracker only when the finding outlives the pull request.

One line, no prose. Evidence lives in the pull request.

```text
ID · date · what was found · severity · fix scope · fix commit · re-verify result · status (open | fixed | withdrawn | won't fix) · sensor added (yes/no, which)
```
